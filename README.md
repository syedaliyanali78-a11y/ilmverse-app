# IlmVerse by Syed Aliyan
Production-Ready Flutter (Dart) Mobile Application

## Setup & Run Commands
```bash
# 1. Install dependencies
flutter pub get

# 2. Run with Gemini API key
flutter run --dart-define=GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

## Required Permissions
- Android: android.permission.RECORD_AUDIO & INTERNET in AndroidManifest.xml
- iOS: NSMicrophoneUsageDescription & NSSpeechRecognitionUsageDescription in Info.plist
